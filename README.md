## 🌟 Overview

Welcome to the repository for my personal portfolio!  
This project showcases my **skills**, **industry experience**, and **featured projects** as a full-stack developer. Built with a modern, high-performance stack, it delivers an immersive user experience featuring 3D interactive graphics, fluid animations, and a responsive layout.

> *"I enjoy building things that didn't exist yesterday. Every project begins with an idea and ends with something people can use."*

---

## ✨ Features

- ⚡ **Cutting-Edge Stack**: Built with React 19, Vite, and Tailwind CSS v4 for lightning-fast load times and instant HMR.
- 🌐 **Interactive 3D Visuals**: Immersive 3D globe and interactive elements powered by **Three.js**, **React Three Fiber**, and **three-globe**.
- 🎬 **Fluid Micro-Animations**: Smooth scroll and entrance transitions created using **Framer Motion** and **Aceternity UI**.
- 📱 **Fully Responsive Design**: Optimized across mobile, tablet, and widescreen desktop breakpoints.
- 🌓 **Dark / Light Mode**: Clean, theme-aware user experience with smooth color transitions.
- 💼 **Experience Timeline**: Detailed breakdown of roles, contributions, and engineering milestones.
- 🚀 **Project Showcase & Deep Dives**: Rich project cards highlighting architecture, tech stacks, and live links.
- 📬 **Interactive Contact Section**: Integrated contact channels, one-click email copying, and resume download.

## 💻 Getting Started

Follow these steps to set up and run the portfolio locally:

### **Prerequisites**
- **Node.js** (v18.0.0 or higher recommended)
- **npm** or **pnpm** / **yarn**

### **Installation**

1. **Clone the repository:**
   ```bash
   git clone https://github.com/NaveedAfraz/Portfolio.git
   cd Portfolio
   ```

2. **Navigate to the frontend directory:**
   ```bash
   cd frontend
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser to view the site.

### **Building for Production**
```bash
npm run build
```
Preview the production build locally:
```bash
npm run preview
```
